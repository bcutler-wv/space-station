# Stopped search administration database inspectors

Version 0.51.0 adds the Astra-reviewed P2b2b2 delivery with two opt-in, one-shot Compose services. The owner-local `scripts/search-admin-db-run.mjs verifier` and `transition` commands first verify the published P2b2b1 credential bundle without changing grants, compare a service-scoped Compose model against the caller's numeric UID/GID and exact role-specific private file, then run the matching fixed service with no dependencies. Each service reads one bounded, repeatable-read, read-only control/history/dispatch snapshot and exits. The transition role's narrow write grants are reserved for future reviewed work; this inspector does not use them. Both SQL search gates remain forced false.

PostgreSQL is attached to its existing default network and the new internal `search_admin_db` network. Only PostgreSQL and the two inspectors attach to the latter; the inspectors have no app, worker, engine or egress network. The credential verifier selects its PostgreSQL authentication endpoint by captured Docker network ID and exact Compose project/network labels, not address order. A valid same-volume PostgreSQL container recreation can change addresses without invalidating the credential bundle. The admin network isolates the tested default-only and separate Docker-bridge targets, while the Docker host and PostgreSQL remain trusted infrastructure.

The dedicated disposable Ubuntu fixture exercises real 1000:1000 and non-default caller/job/file identities, SCRAM login and wrong-password denial through the retained credential verifier, both inspector snapshots, fixed resource/mount/network shape, authorization denials, malformed and mismatched files, absent bind behavior and controlled network targets. It scans private bounded logs for both generated credential values before reporting a fixed result. Docker is unavailable on agent-dev, so this fixture has not passed until its Ubuntu job completes. A launcher timeout does not prove the one-shot container stopped; the operator must inspect the stopped job before retrying. No production policy, credential bundle or search publisher was changed by this slice.
