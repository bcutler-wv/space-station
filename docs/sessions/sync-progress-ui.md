# Sync progress UI

Date: 2026-10-20

Version 0.19.0 presents Gmail import, catch-up, current, retry and repair states with supported/unsupported counts and the last successful mail update. The phase, not that timestamp, determines whether catch-up is complete. One native EventSource under the full authenticated gate shares updates across routes. Background requests use only passive sync endpoints and coalesce changes before fetching private progress.

The client closes a failed stream before bounded reconnection, pauses it in hidden tabs and closes it on logout. Confirmed session loss clears private queries and credentials, then initializes a fresh anonymous CSRF token for sign-in. Transport failures do not trigger ordinary auth-status requests or extend session lifetime. The progress panel uses the existing Material tokens and Rubik typography; its status line is announced separately from message counts.

Local lint, typecheck, 61 unit tests, build, color and license checks passed. The full preview suite passed 18 tests with four authentication cases skipped in that configuration. A disposable HTTPS/PostgreSQL 15 browser fixture verified real SSE phase updates, bounded minimal event payloads, passive session timestamps, reconnect identity, secret clearing and logout. Desktop light and mobile dark captures were inspected. The diagnostic servers were stopped. Astra review identified stale requests being reused after reconnect and missing deadlines on primary progress reads. The corrections cancel obsolete requests, require a new snapshot after reset, and bound headers and body consumption to five seconds. Ordinary events let a valid slow request finish and schedule one trailing refresh. Focused browser regressions passed for hide/reconnect, logout, continual events during a slow read, and timeout recovery; unit tests covered a stalled response body. Astra independently reproduced the original race with the actual component and QueryClient and verified the fix. The longer HTTPS fixture predates these lifecycle corrections.
