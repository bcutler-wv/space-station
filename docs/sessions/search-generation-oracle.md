# Search generation expected-state foundation

The pure database classifier and search security-policy comparator are independently Astra-reviewed and integrated in 0.54.0. Local checks passed; the shared-baseline Ubuntu engine regression remains pending. They add no engine request, database mutation or serving path. Registry `ready` means evidence is eligible for a later engine check; it does not attest the engine or enable either SQL search gate.

The classifier validates complete bounded control, history and dispatch input. It accepts explicitly enrolled disabled v1 or a fully attested v2 registry with exact historical dispatch evidence. Partial transitions, unknown sends, unresolved abandonment, unavailable generations and stale request identities return fixed non-success categories without a partial expected inventory. Historical retained indexes remain required; observing an index never enrolls it or settles an uncertain request.

The search package builds expected roles and mappings from the ready inventory, the eight pinned upstream static roles and frozen v1/current v2 permissions. Its full-collection comparator rejects extra or missing names, altered grants, unknown fields and nonempty restrictions. Only the documented omitted/empty defaults normalize away. The existing disposable engine proof shares the same static baseline, whose upstream provenance and Apache-2.0 notice remain in THIRD_PARTY.md. No dependency was added.

Independent review corrected accessor execution, decorated Date values, custom array prototypes, duplicate engine UUIDs, impossible dispatch prefixes and order-dependent rejection reasons. Focused tests and independent adversarial probes passed. Input callbacks are rejected before traversal or serialization, results are deterministic, and neither package imports the other at runtime.

Complete bounded database reads, engine UUID/profile/alias and public-certificate checks, hidden security collection visibility and the combined administration-container boundary remain separate implementation work. Retained bootstrap must also stop creating a missing v1 index before that engine verifier is accepted.
