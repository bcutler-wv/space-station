# Safe mail body component

Version 0.22.0 adds a reusable authenticated message body at `/mail/body/:accountId/:itemId`, with optional Orbit scope. Full mail navigation follows separately. Stored HTML is sanitized again with pinned DOMPurify and the shared conservative policy. Incoming authority and resource attributes are removed; exact API-proven image refs are reconstructed after sanitation. The message stays in an opaque, scriptless sandboxed iframe. Safe links open an isolated tab. Parent CSP permits self-hosted scripts, with the theme prepaint moved to a local file.

CID images load through scoped authenticated POSTs by default. Remote images require effective consent. The API exposes only bounded opaque ref kinds, never source or proxy URLs. A current explicit per-message choice now overrides the account-scoped claimed-sender preference, including a false choice; absent or stale choices use that preference. This product clarification makes blocking one message work without changing the sender setting for other messages.

The browser allows four active image requests, 64 refs, 2 MiB per PNG and 32 MiB of displayed PNG bytes. Ten-second deadlines cover response consumption. Data URLs carry only validated backend PNG bytes because parent blob URLs did not render in the opaque frame. Base64 expands the maximum image source text to about 43 MiB before DOM copies. Logout immediately clears private state, aborts reads and mutations, and prevents queued or late work. Scope generations isolate same-document item and Orbit changes. Mount cleanup remains compatible with development Strict Mode replay.

Astra review identified and corrected logout and stale mutation lifetimes, incomplete race and stream-limit tests, and a development Strict Mode closure regression. Local checks passed 67 unit tests, lint, typecheck, build, colors and licenses. Fifteen production-bundle browser tests and a dedicated actual Vite development test passed. Astra independently reproduced the original logout and Strict Mode failures and verified their fixes. The fresh PostgreSQL 15 HTTP fixture passed consent precedence, ref kinds, scope and authorization checks; the disposable server was stopped. Both themes and mobile/desktop captures with actual controls, long mail, a safe link and decoded image were inspected.

The browser suite covers hostile external and same-origin staging/rendering requests, link opener isolation, decoded images, revocation with pending requests, logout, same-document races, genuine chunked size/deadline limits, concurrency and aggregate display limits. The dedicated Strict Mode test has its own CI step and is excluded from production browser projects. Ubuntu PostgreSQL 16/Compose and full browser acceptance remain pending for this version.
