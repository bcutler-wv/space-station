Version 0.91.0 binds the existing constructor-issued, deeply frozen writer-mapping contract to one pinned OpenSearch JavaScript SDK 3.9.0 admin mTLS client. The fixed call is `createRoleMapping` for `station_indexer_<T>` with exactly one reserved writer principal in `users` and empty `backend_roles` and `hosts`. The factory checks issued provenance before reading input or TLS files. Its no-argument `sendOnce()` latches before the sole original producer and uses the existing abortable 32 KiB/5-second, zero-retry envelope. It returns a frozen finite result only for the original HTTP 201 with exact two-field `CREATED`/quoted-target message; replacement 200/`OK`, missing or extra fields, wrong target, malformed or oversized body, lost response and timeout cannot confirm it. It never uses GET readback as acknowledgement. `close()` ends the same client, and the per-instance latch is not durable replay protection.
