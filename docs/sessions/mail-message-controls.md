# Mail message controls and recovery

Version 0.31.0 of the Mail view provides explicit per-message archive, read/unread and existing Gmail user-label actions. Opening a message does not mark it read. Controls use verified provider options, the current item snapshot and a stable request key; uncertain writes are never automatically replayed. Confirmed provider state remains separate from the synchronized local view.

An account-selected pending-change view supports exact Orbit filtering and signed cursor pagination. Recovery uses each operation’s original scope. Discovery now includes a bounded subject and thread ID only from a currently live same-account message still in that original scope; unavailable context stays null. This is a product-contract addition recorded in DATA_MODEL and ADR 0012. Status checks preserve the context, and copy distinguishes direct confirmation from merely observing the requested state.

Astra review found and corrected Orbit-filter widening, stale replies restoring uncertainty after terminal success, missing readable recovery context and ambiguous confirmation wording. Parent Orbit changes remount the recovery view so old rows cannot remain visible. Independent review passed the original two failure probes, 32 production-preview and 14 real Vite browser tests, and a fresh PostgreSQL 15 authenticated fixture. Full local lint, typecheck, 85 unit tests, build, color and license checks passed. Screenshots were inspected in light/dark and mobile layouts.
