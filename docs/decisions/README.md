# Decisions

One short file per significant decision, named `NNNN-short-title.md`:

- **Context:** what needed deciding.
- **Options:** what was considered.
- **Decision:** what was chosen and why.
- **Consequences:** what this makes easier or harder.

Decisions already made during the spec phase are recorded across the other docs. Start new records here from milestone 0, beginning with every choice marked "evaluate" in ARCHITECTURE.md.
